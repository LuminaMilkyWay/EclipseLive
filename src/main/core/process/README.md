# core/process

外部进程服务（任务卡 **T41**，用户明确批准新增）。

## 职责

- `launch(exePath, args)`：启动外部可执行文件（**不用 shell**，只传路径 + 参数数组）；
- `isRunning(pid)`：探测进程是否存在（信号 0，不真的发信号）；
- `terminate(pid)`：终止进程（仅用于"由本软件启动且用户选择同时关闭"的实例）。

## 边界（红线）

- **不碰任何既有服务与接口**；不引入新依赖（只用 `node:child_process`）；
- 启动的进程 `detached + unref` ⇒ **本软件退出默认不关闭外部进程**（OBS 默认保留）；
- 面向用户的使用方式见 `TASKS/T41-obs-autolaunch.md`：路径探测不查注册表，
  已在运行时不启动第二个实例，用户手动启动的实例**永不**被本服务关闭。
