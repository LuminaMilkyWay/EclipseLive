## 关于 Harmony 协议（署名）

Harmony 协议由 **Project Harmony**（<https://www.harmonyagreements.org/>）起草，
采用 **Creative Commons Attribution 3.0（CC BY 3.0）** 许可发布，允许在**署名**前提下
逐字复用与适配。本目录内的 PDF 为**未修改的官方文档**，署名与来源如上。

本项目**只采用其中的标准文本**：不改条款、不加附加限制（符合 Harmony 的设计初衷）。

## 适用法律与管辖地（请在签署前阅读）

Harmony CLA 的「**Governing Law and Jurisdiction**」一栏需要由项目填写。
本项目的填写为：

> **适用法律：中华人民共和国法律；管辖：有管辖权的人民法院。**

（这是维护者当前的选择；如需变更，请改本段并在 PR 中说明 —— 变更前已生效的签署仍然有效。）

## 怎么签（个人）

1. 阅读 [`ha-cla-i-v1.pdf`](ha-cla-i-v1.pdf)；
2. 在 PR 描述中写明：

   ```
   I have read and agree to the Harmony Individual CLA (docs/cla/ha-cla-i-v1.pdf).
   Signed: <你的姓名> <你的邮箱>
   ```

3. 维护者会把你的条目登记到 [`CLA-SIGNATORIES.md`](../../CLA-SIGNATORIES.md)。

## 怎么签（公司/组织）

由**授权代表**在 PR 中作出同样声明，并注明：实体全称、注册地、授权代表姓名与职位、
以及"本实体同意 Harmony Entity CLA（`ha-cla-e-v1.pdf`）"。登记后，该实体员工在此范围内的贡献视为已覆盖。
