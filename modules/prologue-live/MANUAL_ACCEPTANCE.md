> 配套 [ACCEPTANCE.md](./ACCEPTANCE.md) 清单逐项展开：前置条件 → 操作步骤 → 预期结果 → 失败排查。
> 每项完成后回到 ACCEPTANCE.md 勾选对应条目。发布前逐项执行；packaged 项（T32-6）可延至下次发版。

## 0. 前置准备

### 0.1 运行形态
| 形态 | 命令 | 说明 |
| --- | --- | --- |
| 开发态（推荐首验） | `npm run dev` | 模块目录 `modules/prologue-live/` 直接被发现加载；改代码热重载需重启应用（import 缓存，模块升级同理） |
| 打包态 | `npm run dist` 后安装 | extraResources 把 `modules/` 种子到 userData；仅 T32-6 需要 |

### 0.2 环境准备
- **OBS Studio**（≥28，浏览器源可用）+ 一个 1280×720 场景源。
- **游戏窗口化全屏测试**：任意窗口化全屏/无边框游戏（悬浮窗置顶/穿透项用）。
- 观察日志：`%APPDATA%\EclipseLIVE\logs\eclipselive-YYYY-MM-DD.log`（脱敏；模块日志前缀 `modules:prologue-live`）。

### 0.3 权限确认
- 模块清单声明 `window-overlay` / `global-shortcut`；首次加载即授予。
- 如曾撤销过权限（`permissions` 撤销记忆持久化），需在设置页重新授予后**重启应用**（grant 不自动恢复，契约行为）。

### 0.4 已知约束速记（出现下述现象属预期，勿误报）
- 独占全屏游戏下悬浮窗不保证可见；穿透开启后输入框不可点（恢复三入口见 C 节）。
- 悬浮窗与 OBS 样式是两套独立配置。

## 1. 快速冒烟（5 分钟，先过此关再逐项）

1. `npm run dev` 启动 → 左侧"扩展"二级菜单出现 **PrologueType Live**（无 404）。
2. 进入控制页 → 输入文字 → 点「发送」。
3. 另开浏览器标签访问「获取URL」复制出的地址（或直接贴进 OBS 浏览器源）→ 逐字显示。
4. 控制页调文字色滑块 → OBS 页文字颜色实时变化。
5. 勾选「悬浮窗-启用」→ 桌面出现透明小窗，输入+Enter 发送 → OBS 继续播放。
6. 按 `Ctrl+Shift+T` → 悬浮窗穿透（点击落透）；再按一次恢复。

全过 → 进入逐项；任何一项不过 → 按该项"失败排查"处理。

## 2. 用户需求第八节逐条（对照 ACCEPTANCE.md 二、）

### 2.1 左侧二级菜单出现模块；控制页渲染正常
- 操作：启动应用 → 左侧"扩展"分组。
- 预期：「PrologueType Live」nav-item 在位；点击后内容区渲染控制页（标题 + OBS 浏览器源区 + 输入区 + 两组设置），无 404/空白/占位壳。
- 失败排查：二级菜单未出现 → 模块未启动（日志 `modules:prologue-live` 有无 `init`/`failed`）；页面空白 → `GET /prologue-live/control` 返回状态与 contentType（对应单测 m7-closeout 已锁，开发态自查：浏览器开 `http://127.0.0.1:<端口>/prologue-live/control?token=…`）。

### 2.2 「获取URL」复制 + 已复制提示
- 操作：控制页顶部点「获取URL」。
- 预期：Toast「已复制」出现；页面**无** URL 明文；粘贴到任意输入框得到 `http://127.0.0.1:<端口>/prologue-live/obs?token=…`。
- 失败排查：Toast「复制失败」→ 剪贴板被系统/沙箱拦截（核对 settings 剪贴板权限；容器对自家网关 origin 已放行 clipboard-sanitized-write，正常不触发）；URL 含 `localhost` 亦可（OBS 同机可达）。

### 2.3 OBS 逐字显示；未发送不显示
- 操作：OBS → 添加浏览器源 → 粘贴 2.2 的 URL；源尺寸 1280×720。控制页发送一段文字。
- 预期：OBS 源内以打字机节奏逐字显示该段落；**未发送时 OBS 源全透明/空白**。
- 失败排查：OBS 空白 → 源刷新一次（F5 在 OBS 源属性）；确认 token 未过期（重启应用后旧 URL 失效，需重新复制）；逐字不出现 → 检查 WS 连接（OBS 源页面 `ws.onclose` 重连逻辑 1s 重试，网关正常即自动恢复）。

### 2.4 速度 / 滚动 / 符号 / 字体 / 文字色实时可调
- 操作：播放一段长文字，逐一拖动控制页滑块/改字段。
- 预期（均**播放中**实时生效）：
  - 打字速度：逐字间隔跟随（`typingSpeed` ms/字）。
  - 滚动速度：内容超高时的行上移过渡时长跟随（`scrollSpeed`）。
  - 开头/结尾符号：改为 `【` / `】` → 新发送段落前后包裹（已播段不回改，属预期）。
  - 字体：白名单下拉 + 手输任意名（如 `SimHei`）→ OBS 同步换字体；不存在的字体名静默回退系统字体（预期，手输兜底）。
  - 文字色：调色盘 → OBS 即时变色。
- 失败排查：改字段后 OBS 不变 → 检查控制页 WS 上行（`type:'config'`）与入口 onChange 广播；范围条走 150ms 防抖，松手后生效属正常。

### 2.5 六样式 + 调色盘全参数实时生效
- 操作：播放段落时切六样式按钮 + 调背景/外框/模糊/透明度/外框宽度。
- 预期：无底图=透明底（OBS 源内只见文字）；高斯模糊=半透明底+backdrop blur；纯色=不透明底；各 ×有外框=描边随 borderWidth/borderColor；透明度/模糊实时变化。
- 失败排查：backdrop-filter 需 Chromium 源支持（Electron 44 内嵌，正常）；样式由 CSS 变量注入（`--pt-*`），页面元素 `data-pt-style` 正确即可。

### 2.6 OBS 源长宽自适应
- 操作：拖动 OBS 浏览器源四角改尺寸（或改源属性分辨率），观察文本区。
- 预期：文本随宽度换行、超高行滚动正常；不裁切/不拉伸/不错位（`ResizeObserver` 重算 + translateY 底部对齐）。
- 失败排查：残留错位 → 源尺寸频繁变化时 CSS transition 未结束即重算（轻微抖动可接受）；换行异常 → 确认 `.para` 白名单 `pre-wrap` + `break-all` 在位。

### 2.7 悬浮窗全套（详见 C 节，逐项以 C 为准）
- 预期：启用/置顶/拖动/缩放/记忆/吸附/多屏/透明度×2/穿透（C1–C9 逐项）。

### 2.8 关闭悬浮窗互不影响
- 操作：悬浮窗开着 → Alt+F4 关闭 → 回控制页与 OBS。
- 预期：控制页/OBS 正常；悬浮窗「启用」自动复位（float-changed enabled=false）；重新勾选可再建。
- 失败排查：未复位 → 检查 onClosed 路径（对应单测 m4 onClosed）。

## 3. 悬浮窗专项（T27 九项 · 对照 ACCEPTANCE.md 三、）

> 每项前置：控制页勾「悬浮窗-启用」+ 游戏以**窗口化/无边框全屏**运行。

### T27-1 显示不抢焦点 + 点击可打字
- 操作：游戏窗口化全屏运行时勾选启用。
- 预期：悬浮窗出现**不最小化游戏、不抢焦点**（showInactive）；点击输入框可直接打字。
- 失败排查：抢焦点 → 属核心宿主问题（T26 showInactive），升级核心核对；无法打字 → `focusable` 被改（模块固定 true）。

### T27-2 置顶层级
- 操作：游戏/浏览器窗口与悬浮窗叠放。
- 预期：悬浮窗覆盖其上；`screen-saver` 层级**不遮挡**系统对话框（如音量条）。
- 失败排查：被游戏覆盖 → 独占全屏时属预期（见约束）；窗口化全屏仍被盖 → 检查 alwaysOnTop 设置。

### T27-3 穿透开启 + 恢复三入口
- 操作：① 按 `Ctrl+Shift+T` 开穿透 → 点击应落到下层应用、悬浮窗显示穿透提示；② 托盘「悬浮窗：关闭鼠标穿透」；③ 再按 `Ctrl+Shift+T`。
- 预期：三入口任一均可恢复点击；恢复后提示条消失、输入框可用。
- 失败排查：快捷键无效 → 冲突被系统/其它应用占用（控制页浮窗组错误条会显示"冲突"，改键即可）；托盘项灰置 → 无穿透中的窗口（正常）；权限被撤销 → 控制页错误条提示，重新授权+重启。

### T27-4 resize 手柄 + 记忆往返
- 操作：拖右下角 grip 改大小；拖标题区（输入框外）移动位置；关闭悬浮窗再启用。
- 预期：grip 拖拽实时缩放（透明窗经 `eclipseliveOverlay.resize`）；位置/尺寸在重启应用后仍保持（debounce 落配置）；拖动中不写盘（停止 500ms 后才落配置）。
- 失败排查：grip 无效 → 页面无 `eclipseliveOverlay` 桥（T27-7 抽验项）；重启丢失 → 配置 `float.x/y/width/height` 是否写入（日志无 rejected 警告）。

### T27-5 多屏 + 拔屏钳制
- 操作：双显示器 → 控制页「显示屏幕」选副屏。
- 预期：悬浮窗出现在副屏；**拔掉副屏**后窗口回收到剩余屏（核心 bounds 钳制）。
- 失败排查：选屏后无变化 → 屏幕 id 与系统枚举不符（重进控制页刷新 select）；拔屏后消失 → 属核心回收，重启模块或重新勾选启用可重建。

### T27-6 权限撤销 → 窗口立即消失；重新授权可重建
- 操作：设置页撤销 `window-overlay` → 勾选启用无效（错误条提示）→ 重新授权 → **重启应用** → 勾选启用。
- 预期：撤销瞬间窗口销毁；授权后重建成功。
- 失败排查：授权后仍失败 → grant 需重启（契约）；错误条持续 → create 失败原因（权限/URL origin）。

### T27-7 主窗页面无 `eclipseliveOverlay` 桥
- 操作：应用内控制页 DevTools（主窗富桥页面）输入 `window.eclipseliveOverlay`。
- 预期：`undefined`（桥只在悬浮窗 preload 注入）。
- 失败排查：非 undefined → 结构性回归，报核心。

### T27-8 `overlay:resize` sender 校验
- 操作：主窗页面手动执行 `ipcRenderer` 风格发送（实际无法访问）；抽验以主窗 DevTools 尝试发送该 IPC。
- 预期：被主进程忽略（不调整任何悬浮窗）。
- 失败排查：有窗口被误调整 → 核心 sender 校验回归，报核心。

### T27-9 独占全屏行为
- 操作：游戏切**独占全屏**。
- 预期：不保证可见（控制页文案明示）；**不反复抢焦点、不致游戏最小化**；无边框/窗口化全屏可用。
- 失败排查：反复切出/抢焦点 → 核心 showInactive 回归，报核心。

## 4. 控制页 / 端口 / 打包（T32 七项 · 对照 ACCEPTANCE.md 四、）

### T32-1 二级菜单进出不闪烁
- 操作：扩展组内反复切 PrologueType Live ↔ 其它页（如设置）。
- 预期：进入秒开（视图保活）、无闪烁；切走内容区正常回 React 页。
- 失败排查：闪烁 → 槽位预创建/显隐时序（T30/T31），属核心，报核。

### T32-2 槽位矩形跟随主窗 resize
- 操作：拖拽主窗边缘改大小。
- 预期：模块页实时贴合内容区（无错位/残留）。注：窗口级截图不含 WebContentsView，需肉眼验收。
- 失败排查：错位 → ResizeObserver 上报频率；报核。

### T32-3 端口漂移
- 操作：设置改网关端口偏好 → 重启应用 → 观察三端。
- 预期：控制页 reload 正常加载（webtools reload）；悬浮窗以新 URL 重建（bounds 从配置恢复）；OBS 源被 obs 桥自动重写；**旧 URL 失效**（重新复制 2.2）。
- 失败排查：悬浮窗未重建 → port-changed 订阅路径（对应单测未覆盖真机，此项即补位）；OBS 不自动重写 → obs 桥联动，报核。

### T32-4 clipboard 特例
- 操作：模块页「获取URL」复制；对比 example-web（第三方工具）内尝试复制。
- 预期：模块页复制生效（已复制 Toast）；example-web 复制被拒（onDenied 计数 +1）。
- 失败排查：模块页被拒 → 容器 selfOrigin 特例，报核。

### T32-5 最小化/托盘往返
- 操作：最小化主窗 → 还原；关闭到托盘 → 从托盘还原。
- 预期：往返后模块页视图状态正常（可继续操作）。
- 失败排查：空白 → 视图重建时序，报核。

### T32-6 packaged 种子链路
- 操作：`npm run dist` → 安装 → 打开应用。
- 预期：模块/页面/悬浮窗/快捷键完整可用（T27 清单同跑一遍）。
- 失败排查：模块缺失 → extraResources 种子未更新（modules/ 目录含 prologue-live 即应入包）。

### T32-7 T28 材质观感
- 操作：模块页占位壳与三档材质对照。
- 预期：不额外适配即达标（材质由全局 CSS 变量承载）。

## 5. 快捷键与样式包补充（对照 ACCEPTANCE.md 五、）

### 5.1 快捷键冲突显式上报
- 操作：将「穿透快捷键」改为系统已占用键（如 `Win+L` 附近）→ 观察控制页。
- 预期：错误条显示"穿透快捷键冲突（<键>）…"；另一键（发送）仍可用；改回空闲键 → 恢复正常。
- 失败排查：无提示 → syncShortcuts 未触发（改键后需保持 float 启用态；此项由单测 m5 锁定，真机复核）。

### 5.2 样式包 import/export（.elstyle）
- 操作：设置页导出 obs 样式包 → 改配置 → 导入该包。
- 预期：obs 组恢复包内值；**float 组不受影响**；导出的 obs 包不含 float 键。
- 失败排查：对组污染 → makeStyleHandler apply/export 路径（单测 m6 锁定，真机复核）。

## 6. 回滚与清理（验收完成后）

- 模块级回滚：应用内禁用/卸载 `prologue-live`（配置分区与撤销记忆保留，属契约行为）。
- 代码级回滚：逐卡 `git revert`；核心侧两处（vitest include / modules-wiring 断言）单独还原。
- 清理：OBS 浏览器源删除；测试期写的 `float.*` 位置配置可在控制页复位或重置模块配置分区。
